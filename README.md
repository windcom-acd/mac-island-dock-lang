# Mac Island & Dock: language files

Translations used by my personal fork of the Windhawk mod
[Mac Island & Dock](https://github.com/ramensoftware/windhawk-mods/blob/main/mods/mac-island-dock.wh.cpp)
by caliberda. The texts come from that mod (version 3.3.0), moved out of its source.

Each `lang/<code>.lc` file is UTF-8, one `English<TAB>translation` pair per line, with `\\`, `\n`,
`\t` and `\r` written as escapes. The mod downloads the file it needs on first use.

original author and its translators.
